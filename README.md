# Meadows

A shareable RiceWM appearance recipe.

[Try this rice in RiceWM](https://env.now/ricewm/gh/cwittenberg/ricewm-recipe-meadows)

## Use this recipe

Open Rice Hub → Work recipes → Import recipe JSON, choose the downloaded .rice.json file and review it. Choose Run recipe to apply it.

## What is included

Recipe settings, the saved wallpaper image and its credits, this README and any included custom theme. Referenced applications, widgets and documents must be available in the receiving environment; personal file contents, account credential stores and running processes are not included. The preview reports missing resources before a run.
